# Home Assistant App: llama.cpp

_Run local language models on your Home Assistant system._

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

[llama.cpp](https://github.com/ggml-org/llama.cpp) gives you a chat web UI
inside Home Assistant and an OpenAI-compatible API, which is what Home
Assistant's llama.cpp integration connects to. Models are GGUF files, downloaded
from Hugging Face or copied into `/share/llama_cpp/models`.
